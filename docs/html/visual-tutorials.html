最终判断口诀

Provider

看域名和服务归属：谁提供模型或平台能力。

Protocol

看路径、字段和响应语义：接口长得像谁。

Adapter

看 SDK / CLI / Framework 怎么接：专属适配还是通用转接。

Harness

看是否编排任务、执行工具、管理权限、产出日志和证据。

结论：Compatible 不是低级，Native 也不是万能。要快速接入和多厂商切换选 Compatible；要完整能力和长期深度集成选 Native；要工具执行、文件修改、审批和证据链就进入 Harness / Agent Runtime 层。
